# ACORN Acoustic Frequency-Response Measurement

This document records the procedure used to measure and plot the acoustic frequency response of **ACORN (Autonomous Configurable Outdoor Replay Node)** on **October 22, 2026**. It documents the initial test; it is not a calibrated absolute-SPL certification.

## Equipment and software

- **Device under test:** ACORN playback system (PCM5102A DAC, MAX9744 amplifier, Visaton R 10 SC loudspeaker, and enclosure).
- **Measurement microphone:** Blue Snowball iCE (USB); no individual microphone calibration file was used.
- **Measurement software:** Room EQ Wizard (**REW V5.31.3**).
- **File-format conversion:** [ACORN Audio Converter](https://neurotech-hub.github.io/ACORN/utilities/audio-converter/).
- **Analysis/plotting:** Python with NumPy and Matplotlib (or an equivalent reproducible implementation).

The microphone distance, precise axis/angle, environment, amplifier volume setting, and device-specific conversion output parameters were not preserved in the REW export. Record these explicitly on future runs rather than inferring them.

## 1. Generate the stimulus in REW

1. Open **Generator → Sweeps → Measurement** in REW.
2. Generate a **256k-sample logarithmic measurement sweep**, **48 kHz**, at **−12 dBFS**, with an **acoustic timing reference** on the left channel.
3. Save the measurement stimulus as:

   ```text
   256kMeasSweep_0_to_20000_-12_dBFS_48k_Float_LR_refL.wav
   ```

The filename encodes the REW settings (nominal 0–20,000 Hz sweep, 48 kHz, floating-point stereo file, left-channel reference). For subsequent runs, use a measurement stimulus generated by REW rather than an arbitrary linear sine sweep.

## 2. Convert the stimulus for ACORN

1. Open the [ACORN Audio Converter](https://neurotech-hub.github.io/ACORN/utilities/audio-converter/).
2. Import the REW-generated WAV and convert it to ACORN's supported playback format.
3. Save the converted file with the name:

   ```text
   256kmeassweep_0_to_20000_-12_dbfs_48k_float_lr_refl-acorn.wav
   ```

4. Transfer the converted WAV to ACORN's microSD card and verify it plays successfully.

**Important:** Preserve the sweep and acoustic timing-reference content when converting; changes to duration, speed, or channel/reference arrangement can invalidate REW's analysis. The output codec/bit depth should be documented from the converter or the converted file if required for replication; these details were not established by the measurement export.

## 3. Record the speaker response

1. Connect and select the **Blue Snowball iCE** microphone as the REW recording device.
2. Position it consistently relative to ACORN's loudspeaker; record distance, angle, microphone orientation, surroundings, ACORN volume, and grille/enclosure configuration.
3. In REW **Measure**, configure playback **From file**, using the **original REW measurement WAV** (not an independently constructed sweep), and enable **Acoustic timing reference**.
4. Start the REW measurement. When REW waits for the timing reference, manually trigger playback of the **converted WAV** on ACORN.
5. Allow REW to capture and process the sweep; check timing-reference acquisition, input clipping, and the impulse response before accepting the result.
6. Save the REW measurement project if desired and export the measurement as a text file.

Recorded REW measurement name: `ACORN_01 Oct 22`.

## 4. Prepare the frequency-response plot

Input: `ACORN_export.txt`.

1. Skip REW metadata lines (prefixed with `*`) and parse the three numeric columns.
2. Retain **frequency** and **level**; omit phase from the customer-facing plot.
3. Restrict the plotted frequency range to **100 Hz–20 kHz**.
4. Apply **1/6-octave smoothing** in logarithmic-frequency space. For each frequency, average **linear acoustic power** (`10^(dB/10)`) over an octave-fraction window, then convert back to dB (`10·log10(mean(power))`). Avoid directly averaging dB samples. Weighting/interpolation should be specified consistently in the plotting code so plots are reproducible.
5. Calculate the mean of the smoothed response across **500 Hz–2 kHz** and subtract it from the entire curve, producing **relative level (dB)** with a 0 dB reference band.
6. Plot a single response trace using a **logarithmic X-axis**, labels **Frequency (Hz)** and **Relative Sound Level (dB)**, and title **ACORN | Acoustic Frequency Response**.
7. Keep the figure uncluttered: subtle grid lines; no phase trace; no measurement notes, disclaimers, or caption within the figure. Export high-resolution **PNG** plus vector **SVG/PDF**.

Normalization is a relative presentation choice, not an absolute microphone calibration. Leave experimental details and limitations in the surrounding caption.

## 5. Interpretation and limitations

- The curve represents the **complete playback and recording chain** (digital playback, DAC/amplifier, loudspeaker, enclosure, propagation/room, and Blue Snowball microphone).
- The Blue Snowball is **not a calibrated measurement microphone**; its own spectral response can influence the measured roll-off and peaks.
- The current result is appropriate for exploratory comparison, not for assigning an accurate ±dB tolerance or confirming a **100 dB SPL at 1 m** specification.
- Do not label the normalized curve **dB SPL** or **dBFS**: label it **Relative Sound Level (dB)**.
- For definitive specifications, repeat in a documented low-reflection measurement geometry with a calibrated measurement microphone and multiple repeats/angles/units.
